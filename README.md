# iMirror

Экран iPhone на компьютере с Windows через AirPlay («Повтор экрана») в максимальном качестве, которое отдаёт iPhone, и **управление iPhone мышью и клавиатурой компьютера**: тапы, свайпы, прокрутка, набор текста, кнопки «Домой» и «Приложения». Дополнительное железо не нужно: используется встроенный Bluetooth компьютера.

## Установка

1. Откройте **[Releases](https://github.com/Ernomoon/iMirror/releases/latest)** и скачайте `iMirror-Setup-….exe`.
2. Запустите его. Установщик сам добавит правила в брандмауэр Windows, а если нужно, установит Microsoft Edge WebView2 (на Windows 11 он уже есть).
3. Откройте iMirror с рабочего стола или из меню «Пуск».

Требования: Windows 10 1809+ или Windows 11 (64-бит), iPhone и компьютер в одной Wi-Fi-сети. Для управления нужен Bluetooth 4.0+ (есть почти во всех ноутбуках).

## Повтор экрана

1. Нажмите **«Запустить приёмник»**.
2. На iPhone: **Пункт управления → Повтор экрана → iMirror**.

На вкладке «Экран» видно, что iPhone реально присылает: разрешение, кадры в секунду, битрейт, кодек.

**Если iPhone не видит iMirror**, откройте вкладку «Сеть». iMirror объявляет себя в каждой реальной сети компьютера и пропускает VPN и виртуальные адаптеры (Hyper-V, WSL, VirtualBox, WireGuard и др.): через них iPhone до приёмника не достучится. Если адаптер определился неверно, нажмите «Только эта» у нужного. Ещё проверьте:
- сеть Windows «Частная», в роутере нет гостевого режима и изоляции клиентов;
- на iPhone выключен VPN.

## Управление iPhone

1. Вкладка **«Управление»** → **«Bluetooth компьютера»**.
2. На iPhone: **Настройки → Bluetooth** → в разделе «Другие устройства» выберите свой компьютер и подтвердите сопряжение.
3. На iPhone: **Настройки → Универсальный доступ → Касание → AssistiveTouch → Вкл.** Появится указатель мыши.
4. Выберите режим:
   - **Захват.** Кликните по окну iPhone, и мышь с клавиатурой перейдут к нему. **Правый Ctrl** возвращает их компьютеру.
   - **Клик = тап.** Тап происходит там, где вы кликнули по картинке. Нужна калибровка в три клика.

Кнопки «Домой», «Приложения», «Пункт управления» и другие — это дополнительные кнопки мыши. Назначьте их один раз: **AssistiveTouch → Устройства → ваш компьютер → Настроить дополнительные кнопки**. Когда iOS попросит нажать кнопку, нажмите её в окне iMirror.

Если у компьютера нет Bluetooth или Windows не даёт ему работать мышью, подойдёт плата **ESP32** (≈300–600 ₽). Её можно прошить прямо из iMirror: вкладка «Настройки» → «Плата ESP32».

## Честно о пределах

- **120 Гц.** iMirror запрашивает у iPhone 120 Гц и до 120 кадров/с, но системный захват экрана iOS отдаёт не больше 60 кадров/с даже на iPhone с 120-герцовым экраном. Это ограничение iOS.
- **Разрешение** выбирает iPhone. Выше 1080p он отправляет видео только в H.265, и только достаточно новые модели.
- **Мало кадров на статичной картинке** — это нормально: iPhone шлёт новый кадр только при изменении экрана.

## Как это устроено

```
iPhone ──AirPlay (Wi-Fi)──▶ UxPlay (GStreamer, аппаратное декодирование D3D12/D3D11) ──▶ окно видео
  ▲                               │ данные сервиса (IMIRROR_MDNS) и статистика
  │ Bluetooth LE HID              ▼
  └──────── iMirror: объявление в сети (zeroconf), перехват ввода, HID через WinRT GATT
```

- `app/imirror/`: приложение.
  - `core.py` — логика.
  - `webui.py` и `ui/` — интерфейс (WebView2).
  - `mdns.py` — объявление в сети.
  - `winble.py` — Bluetooth-мышь и клавиатура.
  - `hid_engine.py` — планировщик HID-отчётов.
  - `capture.py` — перехват мыши и клавиатуры.
- `receiver/patch_uxplay.py`: патч UxPlay 1.74. Добавляет вывод статистики и передаёт объявление в сети приложению: встроенный mDNS UxPlay работает только через один адаптер.
- `firmware/`: прошивка ESP32 (NimBLE). `hid_engine.py` повторяет её отчёт в отчёт, это проверяется тестами.
- `.github/workflows/build.yml`: сборка на Windows, все тесты, сквозная проверка обнаружения, самопроверка собранного и установленного приложения, установщик Inno Setup и релиз по тегу `v*`.

### Тесты
```
python tests/test_all.py                    # протокол, прошивка и её Python-двойник, точность тапа, ядро
python tests/test_capture_logic.py          # перехват ввода Windows (эмуляция Win32)
python tests/test_discovery.py <uxplay>     # объявление → поиск как iPhone → GET /info
python tests/ui_shots.py <chrome> shots     # снимки интерфейса во всех состояниях
```
