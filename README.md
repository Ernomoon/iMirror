# iMirror

Экран iPhone на компьютере с Windows через AirPlay («Повтор экрана») в максимальном качестве, которое отдаёт iPhone.

## Установка

1. Откройте **[Releases](https://github.com/Ernomoon/iMirror/releases/latest)** и скачайте `iMirror-Setup-….exe`.
2. Запустите его. Установщик сам добавит правила в брандмауэр Windows, а если нужно, установит Microsoft Edge WebView2 (на Windows 11 он уже есть).
3. Откройте iMirror с рабочего стола или из меню «Пуск».

Требования: Windows 10 1809+ или Windows 11 (64-бит), iPhone и компьютер в одной Wi-Fi-сети. Bonjour не нужен: iMirror объявляет себя встроенной службой mDNS Windows.

## Повтор экрана

1. iMirror включает приёмник сам при запуске (или нажмите **«Включить»**).
2. На iPhone: **Пункт управления → Повтор экрана → iMirror**.

На главной видно, что iPhone реально присылает: разрешение, кадры в секунду, битрейт, кодек.

Если приёмник не объявился за 15 секунд, iMirror сам пробует безопасный режим (1080p H.264, без звука), а если и это не помогло, показывает карточку с причиной и последними строками приёмника.

## Управление iPhone

Вкладка **«Управление»**: компьютер становится Bluetooth-мышью и клавиатурой для iPhone, через свой встроенный Bluetooth.

1. Нажмите «Включить», на iPhone откройте **Настройки → Bluetooth** и выберите компьютер.
2. Для указателя мыши включите **Настройки → Универсальный доступ → Касание → AssistiveTouch**.
3. Нажмите «Взять мышь и клавиатуру» или щёлкните по окну с экраном iPhone. **Правый Ctrl** возвращает мышь компьютеру.

Там же кнопки «Домой», переключатель приложений, поиск, громкость, пауза, блокировка и ввод текста.

**Если iPhone не видит iMirror**, смотрите блок «Проверка» на главном экране. Он проверяет подключение к сети, VPN, тип сети Windows, брандмауэр (в том числе сторонний), службу объявления и сам приёмник, и предлагает кнопку исправления для каждой проблемы. Чаще всего мешает VPN на компьютере: выключите его или разрешите в нём доступ к локальной сети.

Журнал работы: `%LOCALAPPDATA%\iMirror\imirror.log`.

## Честно о пределах

- **120 Гц.** iMirror запрашивает у iPhone 120 Гц и до 120 кадров/с, но системный захват экрана iOS отдаёт не больше 60 кадров/с даже на iPhone с 120-герцовым экраном. Это ограничение iOS.
- **Разрешение** выбирает iPhone. Выше 1080p он отправляет видео только в H.265, и только достаточно новые модели.
- **Мало кадров на статичной картинке** — это нормально: iPhone шлёт новый кадр только при изменении экрана.

## Как это устроено

```
iPhone ──AirPlay (Wi-Fi)──▶ UxPlay (GStreamer, аппаратное декодирование D3D12/D3D11) ──▶ окно видео
  ▲                               │ данные сервиса (IMIRROR_MDNS) и статистика
                                  ▼
  iMirror: объявление через mDNS Windows (запасные: Bonjour, zeroconf), проверка сети, Bluetooth-мышь/клавиатура
```

- `app/imirror/`: приложение.
  - `core.py` — логика.
  - `webui.py` и `ui/` — интерфейс (WebView2).
  - `netif.py` — выбор основного адаптера (GetAdaptersAddresses) и регистрация через DnsServiceRegister Windows.
  - `mdns.py` — порядок объявления: служба Windows, Bonjour, zeroconf; сторожевые таймеры.
  - `blehid.py`, `capture.py`, `control.py` — HID через GATT (WinRT), перехват мыши и клавиатуры, кнопки iPhone.
  - `netdiag.py` — проверка сети и исправления, режим Wi-Fi для видео.
- `receiver/patch_uxplay.py`: патч UxPlay 1.74. Добавляет вывод статистики и передаёт объявление в сети приложению: встроенный mDNS UxPlay работает только через один адаптер.
- `.github/workflows/build.yml`: сборка на Windows, все тесты, сквозная проверка обнаружения, самопроверка собранного и установленного приложения, установщик Inno Setup и релиз, когда в `VERSION` новая версия.
