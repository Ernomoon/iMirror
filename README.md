# iMirror — экран iPhone на Windows через AirPlay + управление iPhone с компьютера

**iMirror** принимает «Повтор экрана» (AirPlay) с iPhone на ПК с Windows в максимальном качестве, которое отдаёт iPhone, и позволяет **управлять iPhone мышью и клавиатурой компьютера**: тапы, свайпы, прокрутка, набор текста, кнопки «Домой», «Приложения», «Пункт управления».

| Что | Как сделано |
|---|---|
| Приём AirPlay | Открытый приёмник **UxPlay 1.74** с патчем статистики, установщик собирает его из исходников. |
| Качество | H.265/HEVC, запрос 3840×2160, частота экрана 120 Гц и до 120 кадров/с, аппаратное декодирование на видеокарте (Direct3D 12/11). Окно автоматически подгоняется под экран. |
| Реальные параметры | В окне iMirror видно, **что iPhone реально присылает**: кодек, разрешение, кадры/с (текущие и пик), битрейт. |
| Управление | Плата **ESP32** (около 300–600 ₽) по USB работает как Bluetooth-мышь и клавиатура для iPhone. Джейлбрейк и программы на iPhone не нужны. |

---

## ⚠️ Честно о пределах (важно прочитать)

* **120 Гц.** iMirror сообщает iPhone, что экран 120 Гц, и разрешает до 120 кадров/с (больше 255 не позволяет протокол). Но **системный захват экрана iOS выдаёт не больше 60 кадров/с** даже на iPhone с ProMotion: это ограничение Apple внутри iPhone, приёмник его не обойдёт. Ожидайте **до 60 к/с**. Если когда-нибудь iOS начнёт отдавать больше, iMirror это примет и покажет: запрос уже стоит на максимуме.
* **Кадры/с «плавают».** Когда картинка на iPhone не меняется, iPhone почти не шлёт кадров, и счётчик падает до 0–10. Это нормально. Чтобы увидеть максимум, прокрутите ленту или включите видео.
* **Разрешение.** Решает iPhone, ориентируясь на запрошенную **высоту**. Выше 1080p iPhone шлёт только **H.265**, и только на достаточно новых моделях. Итоговое разрешение видно в строке статуса. В режиме «Свои значения» можно экспериментировать с другими размерами.
* **Сеть.** Для 4K нужен быстрый Wi-Fi 5 ГГц или 6 ГГц (лучше всего, если ПК подключён к роутеру кабелем). На 2,4 ГГц будут рывки.
* **Управление без «железки» невозможно.** AirPlay передаёт картинку только в одну сторону, а iOS не принимает управление от ПК (функция «Повтор iPhone» есть только на Mac). Windows не умеет притворяться Bluetooth-мышью. Поэтому нужна плата ESP32: для iPhone это обычная Bluetooth-мышь и клавиатура.

## Что понадобится

* Windows 10/11 64-бит, iPhone с iOS 14 или новее, **одна и та же Wi-Fi-сеть**.
* Для управления: любая плата **ESP32 / ESP32-S3 / ESP32-C3** с USB (например «ESP32 DevKit V1», «ESP32-S3 DevKitC», «ESP32-C3 SuperMini») и USB-кабель **с передачей данных**.

## Установка (один раз)

1. Распакуйте архив в удобную папку, например `C:\iMirror`.
2. Запустите **`install.bat`** и разрешите права администратора. Установщик сам:
   * поставит Python 3.12 (если его нет) и MSYS2;
   * скачает GStreamer с аппаратными декодерами и соберёт приёмник UxPlay (≈10–20 минут при первом запуске);
   * добавит правило в брандмауэр Windows;
   * создаст ярлык **iMirror** на рабочем столе.
3. Журнал установки сохраняется в `install.log` рядом с установщиком.

> Если Windows спросит о доступе к сети для `uxplay.exe`, разрешите доступ для **частных** сетей. Домашняя сеть должна быть помечена как **Частная**.

## Трансляция

1. Запустите iMirror и нажмите **«▶ Запустить приёмник»** (по умолчанию стоит максимальное качество).
2. На iPhone: **Пункт управления → Повтор экрана → iMirror**.
3. Вверху окна iMirror появятся реальные параметры потока.
   * **Подогнать окно**: картинка 1:1 или максимально крупно без выхода за экран.
   * **Полный экран**: окно без рамок на весь монитор (повторное нажатие возвращает обычный вид).
   * **Минимальная задержка** (включено по умолчанию): видео показывается сразу, без подстройки под звук. Это лучше для управления. Для фильмов можно выключить.

## Управление iPhone

### 1. Прошейте ESP32 (один раз, 1 минута)
Подключите плату к ПК → вкладка **ESP32** → выберите порт и тип чипа → **«Прошить выбранный порт»**.
Если прошивка не начинается, зажмите на плате кнопку **BOOT** и нажмите «Прошить» ещё раз.
После прошивки iMirror сам подключится к плате.

### 2. Подключите iPhone к плате
* iPhone: **Настройки → Bluetooth → «iMirror Remote»** → «Создать пару».
* iPhone: **Настройки → Универсальный доступ → Касание → AssistiveTouch → Вкл.** На экране появится круглый указатель.
* Рекомендуется в разделе AssistiveTouch: **Стиль указателя → Автоматически скрывать → выкл.**, а также настроить **Скорость перемещения** по вкусу (после её изменения повторите калибровку для режима «клик = тап»).

### 3. Назначьте кнопки действий (один раз)
Кнопки iMirror «Домой», «Приложения» и т. д. нажимают дополнительные кнопки мыши. На iPhone:
**AssistiveTouch → Устройства → iMirror Remote → Настроить дополнительные кнопки…** iOS попросит нажать кнопку на устройстве: нажмите соответствующую кнопку **в окне iMirror** и выберите действие:

| Кнопка в iMirror | Кнопка мыши | Действие на iPhone |
|---|---|---|
| ⌂ Домой | средняя (3) | Домой |
| ▤ Приложения | 4 | Переключатель программ |
| ◐ Пункт управления | 5 | Пункт управления |
| ☰ Уведомления | 6 | Центр уведомлений |
| ▣ Скриншот | 7 | Снимок экрана |
| ⏻ Блокировка | 8 | Заблокировать экран |

Боковые кнопки вашей мыши (4 и 5) в режиме захвата тоже передаются, так что «Домой» и «Приложения» будут прямо на мыши.

### 4. Режимы управления (вкладка «Управление iPhone»)

**Захват мыши и клавиатуры** (по умолчанию, работает сразу, без калибровки)
* Кликните по окну iPhone, и мышь с клавиатурой перейдут на iPhone. Указатель iPhone двигается по «сырым» данным сенсора мыши, без ускорения Windows.
* Клик = тап, протянуть = свайп, колесо = прокрутка (вертикальная и горизонтальная). Правая кнопка по умолчанию открывает меню AssistiveTouch, её действие можно переназначить там же, где дополнительные кнопки.
* **Правый Ctrl** возвращает мышь и клавиатуру Windows (клавишу можно сменить). В заголовке окна видно, что управление сейчас на iPhone.
* Клавиатура физическая: печатается в той раскладке, которая выбрана **на iPhone** (Ctrl+Пробел на iPhone переключает язык).
* «Ctrl работает как ⌘»: Ctrl+C / Ctrl+V / Ctrl+A / Ctrl+Z работают на iPhone как привычно на ПК. Клавиша Win при этом работает как Ctrl.

**Клик = тап** (нужна калибровка, 3 клика)
* Клик по картинке iPhone даёт тап ровно в этой точке, протягивание даёт свайп, правый клик — долгое нажатие, колесо прокручивает в точке под курсором. Курсор Windows при этом остаётся свободным.
* Клавиатура идёт на iPhone, пока последний клик был по его окну.
* **🎯 Калибровка тапа:** iMirror трижды сдвинет указатель iPhone, а вы кликните в центр серого кружка. Калибровка сама определит, есть ли у указателя ускорение, и выберет быстрый или точный способ позиционирования.

**Прочее:** «📋 Печать из буфера» набирает текст из буфера обмена на iPhone (латиница или кириллица, раскладка iPhone должна совпадать с языком текста); есть кнопки громкости, паузы и поиска (⌘+Пробел).

## Если что-то не работает

| Симптом | Решение |
|---|---|
| iPhone не видит «iMirror» в «Повторе экрана» | Одна и та же Wi-Fi-сеть; сеть Windows помечена как **Частная**; в роутере выключена «изоляция клиентов / гостевая сеть»; перезапустите приёмник. |
| Чёрное окно / нет картинки | Включите «Программное декодирование» или смените «Вывод» на `d3d11videosink`. Обновите драйвер видеокарты. |
| Картинка только 1080p | Включите H.265 и выберите пресет «Максимум»; старые iPhone не умеют H.265, для них 1080p — это максимум. |
| Рывки в 4K | Wi-Fi 5/6 ГГц или кабель для ПК; пресет 1440p; закройте программы, которые нагружают видеокарту. |
| Плата не определяется | Другой USB-кабель (многие кабели только для зарядки); драйвер CP210x или CH340 для вашей платы. |
| Нет указателя на iPhone | AssistiveTouch включён? «iMirror Remote» подключён в Bluetooth iPhone? Строка статуса на вкладке управления должна быть зелёной. |
| Сопряжение сломалось | Вкладка ESP32 → «Забыть все сопряжённые iPhone», затем на iPhone «Забыть это устройство» и подключиться заново. |
| Мышь «застряла» на iPhone | Правый Ctrl (или клавиша, выбранная в настройках). Крайний случай: Ctrl+Alt+Del. |

## Как это устроено

```
iPhone ──AirPlay (Wi-Fi, H.265)──▶ uxplay.exe (GStreamer, D3D12-декодер) ──▶ окно видео
   ▲                                     │ строки IMIRROR_STATS / IMIRROR_VIDEO
   │ Bluetooth LE HID                    ▼
ESP32 «iMirror Remote» ◀──USB-serial── iMirror (Python): Raw Input + низкоуровневые хуки → команды
```

* `receiver/patch_uxplay.py` добавляет в UxPlay вывод реальной частоты кадров, битрейта и разрешения потока (идемпотентно, с проверкой привязок).
* `firmware/`: прошивка ESP32 (PlatformIO, NimBLE). Составное HID-устройство: клавиатура, мышь с 8 кнопками, медиаклавиши. Протокол с контрольной суммой; команды выполняются строго по порядку (клик никогда не обгонит движение); каждое изменение кнопок и клавиш повторяется через 25 мс, чтобы потерянный Bluetooth-пакет не оставил «зажатый палец».
* `app/imirror/`: приложение (tkinter). `capture.py` — перехват ввода, `bridge.py` — связь с платой и планировщик, `calib.py` — геометрия и калибровка, `receiver.py` — управление приёмником.
* `firmware_bin/`: готовые прошивки для ESP32, ESP32-S3, ESP32-C3.

### Тесты
```
python tests/test_all.py            # протокол, раскладки, геометрия, приёмник, прошивка, точность тапа
python tests/test_capture_logic.py  # логика перехвата ввода Windows (эмуляция Win32)
```
`test_all.py` компилирует **настоящий** код прошивки на ПК (нужен g++) и прогоняет через него байты, которые генерирует приложение. Затем модель указателя iPhone (с ускорением и без) проверяет, что тап попадает в цель с точностью до одного шага мыши.
